P10 finding (fixed): white labels on `RecordRed`/`AccentColor` fills measured 3.08:1 and 2.98:1 in dark mode (2.54/2.09 in dark increased contrast). Separate fill tokens were added; all 32 measured pairs now pass.

Surfaces use system semantic colours (`systemGroupedBackground`, `secondarySystemGroupedBackground`). Measured contrast: `docs/ux/contrast-report.md` (generated by `scripts/contrast_check.py`).

Rules: colour never carries meaning alone — every status is colour + SF Symbol + text (`StatusPill`). Unknown, stale and historically working states never use `PassGreen`.

## Type, spacing, shape, size

- Native text styles only, Dynamic Type everywhere. Timer: `.largeTitle` rounded, monospaced digits.
- Spacing scale 4 / 8 / 12 / 16 / 24 / 32 pt; content margin 20 pt.
- Card radius 16 pt continuous; chips are capsules.
- Primary Start/Stop ≥ 56 pt high; every other target ≥ 44 × 44 pt.
- Motion 220 ms ease-in-out for minor changes; none when Reduce Motion is on. The recording dot pulse is cosmetic and disabled with Reduce Motion.

## Components (App/Sources/DesignSystem/Components.swift)

| Component | Purpose | Guarantees |
|---|---|---|
| `PrimaryActionButton` | Labelled primary action | 56 pt; disabled state shows its reason |
| `RecordingControl` | Start / Stop | Stop is direct, idempotent, no confirmation |
| `StatusPill` | Status chip | Colour + icon + text |
| `SourceStatusRow` | One source's current observation | Uses `StatusPresenter`; meter only from real levels |
| `InputLevelMeter` | Downsampled input level | Labelled as input level; hidden under resource pressure |
| `InlineNotice` | Persistent notice | Stays until resolved; never a toast |
| `RecordingRow` | Library row | Text-first; no media decoding |
| `RecordingSummary` | Result headline | No celebration for partial results |
| `TimelineMarker` | Gap / bookmark entry | Text equivalent of the visual timeline |
| `EmptyState` | Empty/no-result states | One valid next action |
| `SettingsRow` | Settings entry | Native grouped style |

## Evidence-to-copy table

Implemented by `StatusPresenter` (core, tested) → `StatusCopy` (app, localizable).

| Evidence state | Copy | Tone |
|---|---|---|
| AWAITING_USER_SELECTION | Choose what to record | neutral |
| STARTING | Checking audio availability… | neutral |
| CAPTURING | Recording | recording |
| Source CHECKING | Waiting for the first audio | neutral |
| Source CHECKS_PASSING (audio) | Detected · Receiving input | pass |
| Source LIMITED (stale) | No audio received just now · Last audio N s ago | warning |
| Source LIMITED (all-zero) | Only silence received · Conversation audio unconfirmed | warning |
| Optional source never arrived | Unconfirmed · No audio received yet | neutral |
| Required source never arrived | Not available · iOS didn't provide this source | warning |
| Open anomaly (any time) | ‹Source› audio missing mm:ss–mm:ss. This stays in the report. | warning |
| STOPPING / FINALIZING | Recording stopped. Saving your file… | neutral |
| SAVED | Saved — no known gaps | pass |
| SAVED_PARTIAL | Saved with missing sections | warning |
| RECOVERED | Recovered — the end may be missing | warning |
| RECOVERED_PARTIAL | Recovered with missing sections | warning |
| Projection older than 45 s | Status not updated | neutral |

Forbidden words in any status copy (tested in `AppTests/CopyAndSettingsTests.swift`): verified, 100%, guarantee, both speakers, perfect.
