# CallCapture — iPhone recording app (planning stage)

Native Swift/SwiftUI iPhone app that helps a person deliberately record available screen and audio, see honest per-source recording health, recover interrupted recordings and manage a local library.

**Status:** Planning. No application code yet. Nothing here claims call recording works on a device — that is only established by physical testing (roadmap phase P14).
